# 小白貓下班大作戰 · White Cat: Escape from Overtime

18:00，下班時間到了。一隻白貓背起小帆布包，要在老闆追上之前衝進走廊盡頭的電梯。

**▶ 線上試玩：https://hswwork1230-cyber.github.io/white-cat-overtime/**

## 玩法

- 往右跑、跳過老闆丟來的文件夾、訊息泡泡和地上的便利貼
- 被打中會扣 1 格電量（共 3 格），被老闆追上就得回去加班
- 衝進電梯就算準時下班

| 操作 | 鍵盤 | 手機 |
|---|---|---|
| 移動 | ← → / A D | 左右按鈕 |
| 跳躍 | Space / W / ↑ | 跳躍按鈕 |
| 重來 | R | ↻ 按鈕 |

## 關於這個作品

- 單一 `index.html`，HTML + CSS + Vanilla JavaScript（Canvas 2D）
- 角色、場景、音效全部用程式生成，沒有外部圖片或音檔
- 美術方向：低飽和扁平 2D 插畫 × 日系獨立遊戲 × 下班前的黃昏辦公室
- 與 AI（Claude）協作：從需求討論、視覺重設計到難度調整，一步步迭代完成
